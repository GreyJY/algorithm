# algorithm
二、32周省赛路线
第1～3周：Java竞赛基础
学习内容：
- 变量、循环、数组、方法
- 字符串、字符数组
- 类和对象只学比赛需要的部分
- Arrays、Collections
- ArrayList、HashMap、HashSet
- ArrayDeque、PriorityQueue
- Comparator 和排序
- StringBuilder
- long、溢出、取模
- 基础输入输出优化
- 时间复杂度和空间复杂度
配套算法：
- 枚举
- 模拟
- 排序
- 进制转换
- 日期问题
- 简单递推
阶段要求：
- 不看资料写出比赛代码框架
- 能判断 O(n)、O(n log n)、O(n²)
- 完成约40道入门题
- 不要花时间系统学习 Java GUI、网络、数据库、多线程、Spring
Java 最重要的习惯：整数计算默认先考虑是否需要 long。
第4～6周：数组结构与区间算法
把数据结构和算法组合学习：
数据结构	同时学习的算法
数组	枚举、排序、二分
前缀和数组	区间和、二维区间和
差分数组	区间修改
双指针	滑动窗口、去重、区间统计
哈希表	计数、判重、映射


重点内容：
- 一维、二维前缀和
- 一维、二维差分
- 双指针与滑动窗口
- 二分查找
- 二分答案
- 坐标压缩
- 离散化思想
阶段要求：
- 完成45～55题
- 能根据数据范围判断暴力还是优化
- 能独立写出前缀和、差分、二分答案
这一阶段会形成第一个核心反射：
连续区间查询 → 前缀和；连续区间修改 → 差分；答案具有单调性 → 二分答案。

第7～9周：栈、队列、链式思想
学习组合：
数据结构	对应问题
栈	括号匹配、表达式、单调栈
队列	BFS、层序遍历
双端队列	滑动窗口、特殊 BFS
优先队列	Top K、贪心、最短路
链式前向星/邻接表	图的存储


重点：
- 单调栈
- 单调队列
- ArrayDeque 的正确使用
- PriorityQueue 的大小根堆写法
- 不建议比赛中手写普通链表，除非题目要求
完成35～45题。
第10～13周：递归、DFS、BFS与回溯
学习内容：
- 递归结构
- DFS 与 BFS
- 网格搜索
- 连通块
- Flood Fill
- 排列、组合、子集
- 回溯与剪枝
- 记忆化搜索
- 多源 BFS
配套数据结构：
- 邻接表
- 栈与队列
- visited 数组
- 状态编码
阶段要求：
- 完成45～55题
- 能自己设计 DFS 参数
- 能正确撤销回溯现场
- 能区分“最短步数用 BFS”和“遍历所有方案用 DFS”
- 能用记忆化搜索消除重复计算
第14～18周：树、图论和并查集
按下面顺序学习：
1. 树的 DFS、深度、子树大小
2. 图的邻接表表示
3. 图的 DFS/BFS
4. 拓扑排序
5. 并查集
6. Dijkstra
7. Floyd
8. Bellman-Ford/SPFA：理解适用条件，不作为首选
9. Kruskal 最小生成树
对应数据结构：
算法	数据结构
BFS	队列
Dijkstra	邻接表＋优先队列
Kruskal	边数组＋并查集
拓扑排序	邻接表＋入度数组＋队列
Floyd	邻接矩阵
树遍历	邻接表＋递归/栈


阶段要求：
- 完成50～60题
- Dijkstra、并查集、拓扑排序、Kruskal 必须能默写
- 看到题目中的“道路、城市、连通、最短、先后关系”，能快速建立图模型
第19～24周：贪心与动态规划
这是从省奖走向国奖的关键阶段。
先学贪心：
- 区间选择
- 区间覆盖
- 排序贪心
- 优先队列贪心
- 交换论证的基本思想
再学动态规划：
1. 递推与状态定义
2. 线性 DP
3. 0/1 背包
4. 完全背包
5. 多重背包基础
6. 最长上升子序列
7. 最长公共子序列
8. 区间 DP
9. 网格 DP
10. 树形 DP 入门
11. 状态压缩 DP 入门
每道 DP 题强制写四行：
- dp 状态表示什么？
- 状态从哪里转移？
- 初始化是什么？
- 遍历顺序为什么这样？
阶段要求：
- 完成60～75题
- 不能只背转移公式
- 同一道典型题至少完成“记忆化搜索版”和“递推版”
- 背包、LIS、网格 DP 能独立实现
第25～27周：数论、组合与字符串
数论：
- 最大公约数、最小公倍数
- 素数筛
- 质因数分解
- 快速幂
- 模运算
- 扩展欧几里得基础
- 组合数
- 杨辉三角
- 容斥基础
- BigInteger 的使用场景
字符串：
- 字符统计
- 回文
- 字符串哈希
- KMP
- Trie 字典树
- 字符串与数字转换
完成35～45题。
优先级上，GCD、素数筛、快速幂、组合数高于复杂数论；KMP 和 Trie 掌握标准应用即可。
第28～32周：省赛真题冲刺
官方题库能够按 Java、省赛、国赛和组别筛选，应把它作为最后阶段的主训练源。蓝桥杯官方历届真题
真题使用顺序：
1. 较早年份按知识点拆开练
2. 最近5届严格整套模拟
3. Java B 组做完后补：
   - Java A 组中档题
   - C/C++ B 组同类题
   - 历届国赛基础、中档题
每周安排：
- 周一：补薄弱知识点
- 周二：专题题4道
- 周三：专题题4道
- 周四：错题重做
- 周五：模板默写＋短题
- 周六：一场完整真题模拟
- 周日：复盘、重写未通过题
模拟必须做到：
- 完全关闭题解和网络
- 使用当届规定的环境与时长
- 记录每题首次阅读、开始编码、通过的时间
- 赛后补完所有“差一点做出”的题
- 一周后无提示重做错题
三、进入国赛后的6～8周
国赛阶段不应继续无差别刷简单题，而要强化中高档问题。
优先补充：
- 树状数组
- 线段树基础
- 倍增与 LCA
- 强连通分量基础
- 01 BFS
- 多源最短路
- 高级二分答案
- 状态压缩 DP
- 数位 DP 入门
- 树形 DP
- 更强的剪枝和状态设计
- 综合建模题
训练比例：
- 60%：历届国赛真题
- 25%：个人薄弱专题
- 15%：省赛基础题保手感
国奖通常不是依靠做出所有题，而是：
简单题不丢分，中档题尽量拿满，难题通过暴力、部分算法或特殊性质争取分数。

四、每天最高效的训练方式
如果每天有2～3小时，可以这样安排：
1. 20分钟：不看资料复习模板和旧错题
2. 30～40分钟：学习一个新概念
3. 60～90分钟：独立做2～4道对应题
4. 20分钟：整理错误和重新实现
看题解的规则：
- 简单题：独立思考20分钟
- 中档题：独立思考30～40分钟
- 难题：思考45～60分钟
- 看题解时只看提示或核心思路，然后关闭题解自己写
- 仍然写不出才看实现
- 看完代码却没有自己重写，等于没有做过
每道题设置复习周期：
- 当天订正
- 3天后重做
- 7天后重做
- 30天后抽查
五、建立三本账
1. 错题账
记录：
- 题目链接
- 错误类型
- 正确思路
- 自己为什么没想到
- 下次看到什么特征应该想到它
错误分类建议：
- 读题错误
- 算法选择错误
- 边界错误
- 溢出
- 数组越界
- 初始化错误
- Java 性能问题
- 复杂度估计错误
2. 模板账
只保存自己真正理解并能默写的模板：
- 快速输入
- 二分
- 前缀和、差分
- DFS、BFS
- 并查集
- Dijkstra
- 拓扑排序
- Kruskal
- 背包
- LIS
- 快速幂
- 素数筛
- KMP
- 树状数组、线段树
3. 数据范围账
比赛中先看数据范围：
数据规模	常见可接受复杂度
n ≤ 20	指数搜索、状态压缩
n ≤ 100	O(n³) 可能可行
n ≤ 1,000	O(n²) 可能可行
n ≤ 100,000	通常需要 O(n log n)
n ≤ 1,000,000	通常需要 O(n) 或较小常数


这只是经验值，还要结合语言、时限和操作常数。
六、阶段性验收标准
不要按照“视频看了多少”判断进步，要按照下面的结果验收。
第2个月结束
- 100道左右有效题目
- 二分、前缀和、差分、双指针能够独立实现
- 简单题通过率达到80%以上
第4个月结束
- 200道左右
- DFS、BFS、并查集、Dijkstra、拓扑排序能默写
- 能完成大部分基础图论题
第6个月结束
- 300道左右
- 掌握常见 DP 与贪心
- 一套省赛真题能稳定解决基础题和部分中档题
省赛前
- 350～450道高质量题
- 最近5届真题至少完成两遍
- 10场以上完整模拟
- 简单题几乎不因代码错误失分
- 能在限定时间内主动放弃卡题并调整顺序
七、你最应该避免的坑
- Java 基础学半年才开始算法
- 只看视频，不独立写代码
- 一道题不会就立即看题解
- 只刷简单题追求题量
- 直接背 DP 公式
- 同时跟三四套课程
- 只做专题题，不参加限时模拟
- 只收藏模板，从不默写
- 为了竞赛学习大量 Java Web 内容
- 省赛都没稳定就过早钻研冷门高级算法
最推荐的主线是：
一个系统课程负责建立知识框架＋官方真题负责适应蓝桥杯＋少量其他平台题目负责补专题。

你当前的第一个月只需要做好三件事：掌握 Java 竞赛语法、建立复杂度意识、完成40～50道数组/字符串/枚举/模拟题。第4周开始就必须接触蓝桥杯真题，不必等“全部学完”才做。

建议每天固定一个“学习闭环”。以每天2小时为例：
每天固定流程
1. 10分钟：复习
   - 不看答案，回忆昨天学了什么
   - 默写一个昨天的模板
   - 重做一道错题
2. 30分钟：学习新知识
   - 每天只学一个主题
   - 例如数组、前缀和、二分、DFS
   - 搞懂用途、写法和复杂度
3. 60分钟：独立做题
   - 1道简单题熟悉写法
   - 2道标准题训练应用
   - 每题先独立思考20分钟
4. 20分钟：复盘
   - 重新写一遍核心代码
   - 记录错误原因
   - 安排3天后重做
每天最低成果是：
学会1个知识点＋独立完成2～3题＋记录1次错误。

从零开始的第一天
第一步：准备环境，20分钟
安装：
- JDK 17
- IntelliJ IDEA Community
- 注册蓝桥云课题库账号
新建 Java 项目，运行下面的竞赛代码：
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        int a = scanner.nextInt();
        int b = scanner.nextInt();

        System.out.println(a + b);
    }
}
暂时统一使用类名 Main。
第二步：学习基础语法，40分钟
今天只学习：
- int 和 long
- 输入输出
- if
- for
- 一维数组
不要扩展学习面向对象、继承、多线程等内容。
第三步：完成4个小程序，50分钟
按顺序独立实现：
1. 输入两个整数，输出和
2. 输入一个整数，判断奇偶
3. 输入 n，计算 1+2+...+n
4. 输入 n 个整数，输出最大值
每个程序都要自己输入测试数据验证。
例如第四题测试：
输入：
5
3 8 2 10 6

输出：
10
第四步：复盘，10分钟
在笔记中记录：
日期：
今日知识：输入输出、循环、数组
今日完成：4题
出现错误：
1. 忘记数组下标从0开始
2. 求和可能需要long
明天复习：重新写“输入n个数求最大值”
每次学习前的启动动作
以后每天坐下后，直接完成这三个动作：
1. 打开代码编辑器
2. 默写昨天的一个程序
3. 开始今天的第一道简单题
尽量固定时间，比如每天晚上 19:30—21:30。不要用“学了多长时间”衡量效果，记录“独立通过了几道题”。
第一周可以按这个顺序进行：
- 第1天：输入输出、变量、判断、循环
- 第2天：一维数组
- 第3天：字符串与字符数组
- 第4天：方法、参数和返回值
- 第5天：排序与 Arrays.sort
- 第6天：枚举和模拟题
- 第7天：复习＋一次60分钟小测
今天先把上面的4个程序全部独立写出来，就算正式开始。
